# 我が家の献立（menu-app）

家族で共有する献立・買い物リストの PWA です。React + Vite + Supabase で作られています。

## できること

- スマホのホーム画面に追加してアプリのように使える（PWA）
- 家族で「共有コード」を使って同じ献立・買い物リストを見る／編集する
- 献立を1週間単位で計画（曜日ごとにメニューを割り当て）
- 人数（1〜10人）を変えると、材料の分量が自動で計算される
- 献立から必要な食材をワンタップで買い物リストへ追加（同じ食材は自動でまとめる）
- 常備品（醤油・砂糖など）は買い物リストに自動では入らない。必要な時だけ手動追加
- 最初から30種類の家庭料理メニューを収録（材料・作り方つき）。あとから自由に追加・編集・削除可能
- 家族の誰かがスマホでチェックすると、他の家族のスマホにもリアルタイムで反映

## セットアップ手順

### 1. Supabase プロジェクトを準備する

1. [Supabase](https://supabase.com) でプロジェクトを作成します（すでにお持ちの場合はそのまま使えます）。
2. **Authentication → Providers → Anonymous Sign-Ins** を有効にします。
   - このアプリはメールアドレスやパスワードを使わず、匿名認証＋共有コードで家族を識別します。
3. **SQL Editor** を開き、このプロジェクト内の `supabase/schema.sql` の中身を全てコピーして貼り付け、実行します。
   - テーブル（families / family_members / ingredients / menus / menu_ingredients / meal_plan_entries / shopping_list_items）
   - Row Level Security（家族のメンバーだけが自分の家族のデータを読み書きできる設定）
   - 家族の作成・参加用の関数（`create_family` / `join_family`）
   - リアルタイム同期の設定
   がまとめて作成されます。
4. **Project Settings → API** から、
   - Project URL
   - anon / public key
   の2つをコピーします。**service_role / secret key はコピーしないでください**（このアプリでは絶対に使いません）。

### 2. 環境変数を設定する

```
cp .env.example .env
```

`.env` を開き、先ほどコピーした値を入力します。

```
VITE_SUPABASE_URL=あなたのProject URL
VITE_SUPABASE_ANON_KEY=あなたのanon key
```

### 3. インストールと起動

```
npm install
npm run dev
```

ブラウザで表示されたURLを開くと、「家族ルームを作る」画面が表示されます。

### 4. 家族で共有する

1. 最初の1人が「はじめて使う（家族ルームを作る）」からルームを作成します（このとき30種類の初期メニューが自動で登録されます）。
2. 設定画面に表示される **共有コード（6文字）** を家族に伝えます。
3. 他の家族は「共有コードで参加する」からコードを入力するだけで、同じ献立・買い物リストにアクセスできます。ログインやパスワードは不要です。

### 5. スマホのホーム画面に追加する（PWA）

- iPhone（Safari）: 共有ボタン → 「ホーム画面に追加」
- Android（Chrome）: メニュー → 「ホーム画面に追加」／「アプリをインストール」

## デプロイ（家族が実際に使うには）

開発サーバー（`npm run dev`）はあなたのパソコンでしか開けません。家族のスマホからも使えるようにするには、Vercel や Netlify などにデプロイしてください（どちらも無料枠があります）。

```
npm run build
```

でビルドし、`dist/` フォルダをデプロイするか、Vercel/Netlify にこのプロジェクトのリポジトリを接続し、環境変数（`VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY`）を設定してください。

## プロジェクト構成

```
src/
  data/seedMenus.js       初期30メニューのデータ
  lib/                    Supabaseクライアント、家族認証、数量計算、日付処理
  hooks/                  データ取得＋リアルタイム同期（メニュー／食材／献立／買い物リスト）
  components/             共通UIパーツ（ボタン、カード、モーダルなど）
  screens/                各画面（ホーム／献立／買い物／メニュー一覧・詳細・編集／常備品／設定）
supabase/schema.sql       Supabaseに実行するテーブル・RLS・関数定義
```

## セキュリティについて

- ブラウザ（クライアント）に渡すのは anon / public key のみです。service_role key は絶対に使用していません。
- 各テーブルは Row Level Security で保護されており、家族メンバー（`family_members` に登録された人）だけが自分の家族のデータを読み書きできます。
- 家族への参加は「共有コードを知っていること」が条件です。コードは第三者に伝えないよう管理してください。
